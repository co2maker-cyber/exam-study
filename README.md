# 기출 반복 학습

기출문제를 10문제/50문제/전체 단위로 반복해서 푸는 정적 웹사이트입니다. (GitHub Pages로 바로 배포 가능)

## 기능
- **10문제 / 50문제 / 전체** 풀기, 시험·영역(Domain)별 필터
- 출제 방식: 안 푼 문제·오답 우선 / 완전 랜덤 / 오답노트만
- 답을 고르면 **즉시 정답 + 이유(해설)** 표시
- 복수 정답 문제("두 개 선택") 지원
- **오답노트**: 틀린 문제 자동 저장, 틀린 횟수, 메모 작성, 2번 연속 맞히면 자동 졸업
- **용어 학습 표**: 과목별 단어장 — AWS 용어 134개, 네트워크관리사 용어 74개(라우팅 기본·RIP·OSPF·EIGRP·BGP·라우터 명령어·IP 주소·서브넷·DHCP), 정보통신 유지보수 용어 60개(고시·네트워크 기초·통신·방송설비·정보설비·도면·광통신·이동통신). 20개씩 페이지 넘기기, 검색·분류 필터, 뜻 가리기(셀프 테스트), 외운 용어 체크, 용어별 관련 기출 풀기
- **계산 연습**(상단 '연습'): 매번 숫자가 바뀌는 무작위 문제 — 서브넷 계산(네트워크·브로드캐스트·호스트 범위, 2진수 풀이), 마스크·변환(필요 호스트·서브넷 수 → 마스크, /표기 ↔ 마스크 ↔ 와일드카드), 경로 선택(AD·최장 일치·OSPF Cost·RIP 홉), DHCP(DORA 순서, 메시지 주소·포트, 범위 계산, 임대 T1/T2, 장애 상황)
- **단어 추가 · 뜻 찾기**: 모르는 단어를 입력하면 용어 표 → 기출 해설 → 위키백과(한국어→영어) 순서로 뜻을 찾아 주고, 고쳐서 '내 단어'로 저장(수정·삭제 가능)
- **실기 실습장** (상단 **실기** 메뉴): 네트워크관리사 2급 실기 범위를 직접 해 보고 자동 채점받는 도구 세 가지. 실습장별 완료 개수를 함께 보여 줌
  - **라우터 콘솔 연습장** (`router/`): 시스코 IOS 스타일 명령어 415개를 브라우저에서 직접 입력해 보는 시뮬레이터. 실습 14개(자동 체크·힌트·모범 답안)와 자유 연습, PC 연결 진단 패널, ROMMON 비밀번호 복구까지 지원. 자세한 안내는 `router/README.md`
  - **윈도우 서버 실습장** (`windows/`): Windows Server 2016 관리 도구 화면을 흉내 낸 GUI 시뮬레이터. 과제 21개(TCP/IP, DNS, DHCP, IIS·FTP, Active Directory, 보안 정책, 공유·NTFS, 방화벽, 명령 프롬프트). 자세한 안내는 `windows/README.md`
  - **리눅스 서버 실습장** (`linux/`): CentOS 7 터미널 시뮬레이터. 과제 21개(권한·사용자, ifcfg·nmcli, systemctl·firewalld, SSH·httpd, yum·rpm, tar, mount·fstab, cron, find·grep·awk, vi). 자세한 안내는 `linux/README.md`
- 학습 기록 백업/불러오기 (기록은 브라우저 localStorage에 저장)
- 키보드: 숫자키로 선택, Enter로 제출/다음

네트워크관리사는 출제 횟수(★ 3회 이상)로 걸러 풀 수 있고, 문제마다 출제 회차가 표시됩니다. 그림이 필요한 문제(그림 파일 미제공)와 공식 정답이 갈리는 414·432번은 들어 있지 않습니다.

정보통신 유지보수 관리는 기출이 아니라 「정보통신 유지보수 관리 기준 실무 강의자료」(정보통신설비 유지보수·관리기준 고시 2025-48호 포함)와 정리본 내용으로 만든 예상문제입니다. 단원(고시·네트워크 기초·설비 종류·도면·광통신·이동통신)별로 골라 풀 수 있습니다.

## 문제 추가
`data/set5.js` 같은 새 파일을 만들어 `addSet(...)`으로 등록하고 `index.html`에 `<script>` 한 줄을 추가하세요. 형식은 `data/bank.js` 상단에 설명되어 있습니다.

## GitHub Pages 배포
1. GitHub에 새 저장소를 만들고 이 폴더를 push
2. 저장소 **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** 선택
3. 잠시 후 `https://<아이디>.github.io/<저장소명>/` 에서 접속
