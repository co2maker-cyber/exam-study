# 기출 반복 학습

기출문제를 10문제/50문제/전체 단위로 반복해서 푸는 정적 웹사이트입니다. (GitHub Pages로 바로 배포 가능)

## 기능
- **10문제 / 50문제 / 전체** 풀기, 시험·영역(Domain)별 필터
- 출제 방식: 안 푼 문제·오답 우선 / 완전 랜덤 / 오답노트만
- 답을 고르면 **즉시 정답 + 이유(해설)** 표시
- 복수 정답 문제("두 개 선택") 지원
- **오답노트**: 틀린 문제 자동 저장, 틀린 횟수, 메모 작성, 2번 연속 맞히면 자동 졸업
- 학습 기록 백업/불러오기 (기록은 브라우저 localStorage에 저장)
- 키보드: 숫자키로 선택, Enter로 제출/다음

## 문제 추가
`data/questions.js`에 문제를 추가하세요. 파일 상단에 형식 설명이 있습니다.

## GitHub Pages 배포
1. GitHub에 새 저장소를 만들고 이 폴더를 push
2. 저장소 **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** 선택
3. 잠시 후 `https://<아이디>.github.io/<저장소명>/` 에서 접속
