# 기출 반복 학습

기출문제를 10문제/50문제/전체 단위로 반복해서 푸는 정적 웹사이트입니다. (GitHub Pages로 바로 배포 가능)

## 기능
- **10문제 / 50문제 / 전체** 풀기, 시험·영역(Domain)별 필터
- 출제 방식: 안 푼 문제·오답 우선 / 완전 랜덤 / 오답노트만
- 답을 고르면 **즉시 정답 + 이유(해설)** 표시
- 복수 정답 문제("두 개 선택") 지원
- **오답노트**: 틀린 문제 자동 저장, 틀린 횟수, 메모 작성, 2번 연속 맞히면 자동 졸업
- **용어 학습 표**: 기출에 나온 AWS 용어 134개의 뜻·시험 포인트, 20개씩 페이지 넘기기, 검색·분류 필터, 뜻 가리기(셀프 테스트), 외운 용어 체크, 용어별 관련 기출 풀기
- **단어 추가 · 뜻 찾기**: 모르는 단어를 입력하면 용어 표 → 기출 해설 → 위키백과(한국어→영어) 순서로 뜻을 찾아 주고, 고쳐서 '내 단어'로 저장(수정·삭제 가능)
- **로그인 · 클라우드 저장**: Google 또는 이메일로 로그인하면 풀이 기록·오답노트·외운 용어·내 단어가 계정에 저장되어 어느 기기에서든 불러옴 (기기에는 저장하지 않음)
- 학습 기록 파일 백업/불러오기
- 키보드: 숫자키로 선택, Enter로 제출/다음

## 문제 구성
AWS Cloud Practitioner(CLF-C02) 기출 192문항 중 중복 1문항(191번 = 106번)을 뺀 **191문항**입니다. 모든 문항에 정답과 해설이 들어 있습니다.

| 파일 | 내용 |
|---|---|
| `data/set1.js` | 1회 (1~50번) |
| `data/set2.js` | 2회 (51~100번) |
| `data/set3.js` | 3회 (101~150번) |
| `data/set4.js` | 4회 (151~192번) |
| `data/glossary.js` | 용어 학습 표 데이터 |
| `정답표.md` | 전체 정답 한눈에 보기 |

## 문제 추가
`data/set5.js` 같은 새 파일을 만들어 `addSet(...)`으로 등록하고 `index.html`에 `<script>` 한 줄을 추가하세요. 형식은 `data/bank.js` 상단에 설명되어 있습니다.

## GitHub Pages 배포
1. GitHub에 새 저장소를 만들고 이 폴더를 push
2. 저장소 **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** 선택
3. 잠시 후 `https://<아이디>.github.io/<저장소명>/` 에서 접속

## 로그인 설정 (Firebase, 처음 한 번)
학습 기록은 기기에 저장하지 않고 로그인한 계정(Firebase)에 저장합니다. 설정 전에는 기록이 저장되지 않습니다.

1. **프로젝트 만들기**: https://console.firebase.google.com 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 됨)
2. **로그인 방식 켜기**: 빌드 → **Authentication** → 시작하기 → 로그인 방법에서 **Google**과 **이메일/비밀번호**를 사용 설정
3. **데이터베이스 만들기**: 빌드 → **Firestore Database** → 데이터베이스 만들기 → **프로덕션 모드**로 생성 → **규칙** 탭에 이 저장소의 `firestore.rules` 내용을 붙여 넣고 **게시**
4. **사이트 주소 허용**: Authentication → 설정 → **승인된 도메인**에 `co2maker-cyber.github.io` 추가
5. **웹 앱 등록**: 프로젝트 설정(톱니바퀴) → 내 앱 → **웹(</>)** 아이콘 → 앱 등록 → 표시되는 `firebaseConfig` 값을 `data/firebase-config.js`의 `null` 자리에 붙여 넣고 커밋

> `firebaseConfig` 값은 공개되어도 되는 식별 정보입니다. 데이터는 `firestore.rules`에 따라 본인 계정만 읽고 쓸 수 있습니다.
